# Personal-Resume-Website

🌐 Personal Resume Website

A modern, responsive personal portfolio and resume website showcasing Abdur Rahman — a Computer and Communication Engineering student passionate about web development, problem-solving, and UI design. This site highlights education, skills, projects, experience, and certifications in a clean, user-friendly format.

✨ Features

* Responsive Design — Works seamlessly on desktop, tablet, and mobile devices.

* About Me Section — Brief introduction and career aspirations.

* Education Timeline — Academic background from SSC to Bachelor’s degree.

* Skills Overview — Categorized into frontend, backend, tools, and others.

* Projects Showcase — Links and descriptions for notable projects:

  * Online FoodShop Website

  * Temperature Converter

  * Snake Game

  * Students Grade Sheet

  * Tic-Tac-Toe Game

  * TikTok Home Page Clone

  * To-Do List

  * Calculator

  * Online Quiz

* Experience — Internship and participation in workshops and contests.

* Certificates — Links to earned certifications(https://github.com/abdurrahmancce/Achievements).

* Contact Section — Email, phone, and social media links(https://abdurrahmancce.github.io/Personal-Resume-Website/#contact).

🛠️ Technologies Used

* HTML5

* CSS3

* JavaScript (Vanilla)
